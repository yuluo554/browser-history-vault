## 2. 逐棒完成定义（DoD）

### M1 数据先行

- ① 合成库用**假域名白名单**程序化生成（保留域，见 `plan/05` §3）；
- ② 按 `plan/05` §4 清单植入真值：**真值只存输入与期望**（无 `observed_*`），且**期望可由输入独立复算**；
- ③ 生成脚本可复跑且**两层断言**通过（冻结产物形态 + 重生成逐字节一致）；
- ④ `selftest` 真读 fixtures 台账（`manifest.json` 进入 `REQUIRED_DATA_ASSETS`），三处同步（selftest 代码 / `plan/03` K 清单 / `plan/05`）；
- ⑤ 反例样本齐备（不该命中的项逐类都有）。

**演示**：`--check` 退出 0；变异验证（改坏生成器 → 至少一层红）。
**退出码退役**：本棒不解锁用户命令，`STAGE_NOT_READY` 不变。

### M2 归档

- ① 运行中浏览器可用（带 `-wal` / `-shm` 场景）；
- ② 原库 `mtime` 归档前后不变（并加字节 sha256 比对）；
- ③ 重复归档幂等：`visits` 行数不变、`visits_added` 第二次为 0；
- ④ `url_id` 稳定映射（同一 URL 跨多次归档同 id）；
- ⑤ 覆盖区间与缺口如实记录并可查（`status` 落地）；
- ⑥ **退役 `snapshot` / `archive` / `status` 三条未就绪条目**（五处同步，见 `plan/03` §11），并**补三条离线 CI 冒烟**（`K22`）。

**演示**：对合成库跑 snapshot→archive→archive（第二次幂等）→status 打印覆盖区间。

### M3 洞察

- ① 搜索断网可用、重复执行一致、CSV 列序固定可读回；
- ② 会话切分边界三态用例（恰好等于 / 少 1 秒 / 多 1 秒）逐条通过；
- ③ 遗忘的宝藏命中集合与真值一致，报告显示 N 的实际取值；改 N 后结果按定义变化；
- ④ 每个聚合数字可下钻（引用 `visit_id` 可解析 + 行数对账）；
- ⑤ 退役 `search` / `report` 两条未就绪条目 + 补离线冒烟。

### M4 聚类

- ① 固定种子复跑结果逐字段一致；同分同序（打乱输入不变）；
- ② 路径真值一致、跨会话不串；步骤可下钻；
- ③ 会话口径与模块③**同源**（结构断言，禁止第二份会话切分）；
- ④ 退役 `cluster` 未就绪条目 + 补离线冒烟。

### M5 报告

- ① 单文件 HTML：零外链（从严档），断网打开功能完整；
- ② 私密域名零出现（含标题回显、CSV）；敏感域名打码；
- ③ 覆盖区间 + 缺口提示 + 生效口径块在位；
- ④ 渲染层零判定（AST 三条断言 + 双对照）；双跑逐字节一致；
- ⑤ 首启隐私说明落地（标记写用户主目录；只读环境下不失败）；
- ⑥ 退役 `report --html` 相关未就绪语义（若 report 已在 M3 退役，则本棒只补渲染门）。

### M6 发布

DoD 三件套**缺一不可**：①git tag ②GitHub Release（**附产物**）③发布留档（`plan/RELEASE-M6.md`）。
执行清单见 `plan/07`。其中"附产物"= **手工源码包**（可复算 sha256）+ `SHA256SUMS` 伴随文件；
发布留档在打 tag **之前**写好并进 tag 树，tag 之后才产生的事实**分栏追加**。

## 3. 每个里程碑的收尾顺序（固定，不得跳步）

```
DoD 逐项验证（跑命令 + 留证据）
  → plan/00 状态表 / plan/05 / plan/06 状态回写
  → 写下一棒 plan/HANDOFF-M<next>.md（六节齐）
  → commit
  →（有远端则 push 等 CI 绿；无远端则写"本地等价校验（未接远端，CI 待首推验证）"）
```

**硬约束**：**没写完下一棒 HANDOFF 就不算完成这个里程碑**——K 编号、环境坑、证据位置只存在于当下对话的工作记忆里，
"下个对话开头再补"实测必漏。库内一律写相对路径（`plan/HANDOFF-Mx.md`），绝对路径只出现在用户侧启动命令里。
